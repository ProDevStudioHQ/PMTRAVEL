# Cookie statement — DRAFT, NOT PUBLISHED

> For legal review. Do not publish.

**This website sets no cookies.**

That is not a simplification. As built and verified:

- no analytics or measurement of any kind is installed;
- no advertising or tracking pixel is present;
- no third-party embeds (maps, video, social) are used;
- fonts are served from our own origin, not a third-party font service;
- the site uses no session, no login and no `localStorage`;
- the content security policy blocks every third-party origin, so a tracker
  could not be added without a deliberate code change.

There is therefore no consent banner, because there is nothing to consent to.

If this changes — if analytics is ever added — this statement must be updated
and a lawful consent mechanism implemented **before** the change goes live, not
after.
