# PM Travel Agency — website

B2B Morocco ground operations. Next.js 16, React 19, TypeScript, Tailwind CSS 4.

```
npm install
cp .env.example .env.local
npm run dev
```

- **Read first:** [docs/START.md](docs/START.md)
- **Deploying:** [docs/deployment.md](docs/deployment.md)
- **Working with an AI agent:** [docs/AGENT-PROMPTS.md](docs/AGENT-PROMPTS.md)

Two rules override everything else: no operational figure is published unless
it has been verified, and nothing unconfirmed — phone number, legal identity,
statistics — appears on the site in any form.
